# Original MIT course recordings

Source: MIT OpenCourseWare, 15.401 Finance Theory I, Fall 2008, Professor Andrew W. Lo.
https://ocw.mit.edu/courses/15-401-finance-theory-i-fall-2008/

Files are downloaded from the archive.org URLs supplied in MIT's resource metadata. Original source metadata identifies CC BY-NC-SA 4.0; preserve individual notices in the recordings and accompanying original resources.

`session-01.mp4` through `session-20.mp4` are the original recordings. `interview.mp4` is the supplementary Chalk Radio interview. Topic segments use time ranges in these files; videos have not been edited or re-encoded.

Per-recording JSON files and `manifest.json` record provenance, sizes, local SHA-256 hashes, duration and three short decode checks. These sample checks are not a claim that every frame was decoded or visually reviewed. `.part` files are incomplete and must not be used as finished recordings.
